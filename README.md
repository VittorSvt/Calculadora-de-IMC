# 🧮 Calculadora de IMC

Este é um projeto simples de uma Calculadora de IMC (Índice de Massa Corporal), feita com HTML, CSS e JavaScript puro.

## 🚀 Funcionalidades

- Calcula o IMC a partir do peso (kg) e da altura (m).
- Mostra o valor do IMC e uma descrição.
- Layout responsivo e leve.
- Ícones via Font Awesome.
- Link para saber mais sobre saúde.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- [Font Awesome](https://fontawesome.com/)
